<h1 align="center">KiCad 10 Template for CI/CD with KiBot</h1>

A **KiCad 10** project template generating professional documentation and
manufacturing files with [KiBot](https://kibot.readthedocs.io/en/master/),
**locally with Docker** or **on GitHub Actions**, with the same docker image
and the same script.

Heavily inspired by [KDT_Hierarchical_KiBot](https://github.com/nguyen-v/KDT_Hierarchical_KiBot):
same outputs, same `DRAFT` / `PRELIMINARY` / `CHECKED` / `RELEASED` mechanism,
same YAML definitions.

> This file is overwritten by the README generated by KiBot (template:
> `kibot_resources/templates/readme.txt`). The full documentation is in
> **[docs/TEMPLATE_GUIDE.md](docs/TEMPLATE_GUIDE.md)**.

## Outputs

| Status | Generated |
| --- | --- |
| `DRAFT` | Schematic PDF, netlist, BoM (CSV/HTML), README |
| `PRELIMINARY` | + PCB routing PDF, Gerbers PDF, fabrication & assembly PDFs, Gerbers/drill/ODB++/ZIP, pick and place, interactive BoM, testpoints, 3D renders (KiCad or Blender), STEP, KiRI, HTML page |
| `CHECKED` | + ERC/DRC reports |
| `RELEASED` | Same as CHECKED, automatic on `x.y.z` tags, with a GitHub release |

## Quick start

1. **File → New Project From Template** in KiCad 10 (copy `.github/` if KiCad
   didn't).
2. Edit the metadata at the end of [`kibot_yaml/kibot_main.yaml`](kibot_yaml/kibot_main.yaml)
   and the status in [`kibot_settings.yaml`](kibot_settings.yaml).
   Shared KiCad libraries: declare them in `kibot_settings.yaml`
   (`lib_<VAR>_url: https://github.com/...`) and run `./run_kibot.sh --setup-libs`.
3. Generate the outputs:

   ```
   ./run_kibot.sh -v PRELIMINARY            # Linux / macOS / WSL / Git Bash
   .\run_kibot.ps1 -v CHECKED -r blender    # Windows PowerShell, Blender renders
   ```

   or push to GitHub (enable *Read and write* workflow permissions), and tag
   `x.y.z` on `main` for a release.

## Configuration files

| File | Content |
| --- | --- |
| [`kibot_settings.yaml`](kibot_settings.yaml) | Project status, docker image, commit of the outputs and render engine in CI, shared libraries (git submodules) |
| [`kibot_yaml/kibot_main.yaml`](kibot_yaml/kibot_main.yaml) | KiBot parameters (`definitions:`): metadata, 3D render engine, directories, layers... |
| [`kibot_resources/stackups`](kibot_resources/stackups) | JLCPCB 4 layers (default) / 6 layers stackups: `./run_kibot.sh --stackup jlcpcb_6l` |
| [`kibot_resources/templates`](kibot_resources/templates) | Fabrication/assembly notes, impedance table, README template |
| [`CHANGELOG.md`](CHANGELOG.md) | Revision history, synchronised with the schematic and the releases |
